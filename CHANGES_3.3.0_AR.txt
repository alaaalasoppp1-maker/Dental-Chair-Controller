Dental Chair Controller 3.3.0
==============================

- أرشيف سريري يبدأ ببطاقات الخطط القائمة والمنتهية.
- خط زمني يومي لكل خطة مع الوقت والمرحلة والسن والقناة ومصغرات الصور.
- حفظ كل حدث من Doctor Assistant 8.7.0 مع كامل التفاصيل، وإرساله إلى Dental Chain OS 15.72.
- عدم عرض JSON أو الصوت أو خلفيات الخطط أو الصور البانورامية المعلّمة ضمن وسائط المريض.
- تصنيف الصور العادية الملتقطة من المساعد ضمن «صور عادية».
- اختصاران قابلان للتعريف للعرض التقديمي السابق والتالي.
- إيقاف عرض الصورة بأمر من تطبيق المساعد.
- الصور المرسلة للعرض فقط تذهب إلى PresentationCache ولا تلوّث أرشيف المريض.
- تضمين ملف GitHub Actions الكامل `.github/workflows/build-windows.yml` صراحةً داخل حزمة الاستبدال، حتى لو كان مطابقاً للنسخة المرجعية.

الفحص المحلي:
- npm run check: ناجح.
- npm test: ناجح، ويتضمن حدث سلك تقويمي بتفاصيل المقاسات والتحقق من الخط الزمني.
